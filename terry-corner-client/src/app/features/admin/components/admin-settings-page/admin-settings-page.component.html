Quick 2-Minute Setup Guide

  1. Create Free Account: Go to supabase.com and create a new free project.
  2. Run Database Setup: In your Supabase dashboard, click SQL Editor → New Query.
  3. Paste Schema: Open the file supabase-schema.sql located in your project root, copy the entire SQL script, paste it into the editor, and click Run.

    (This automatically creates all 5 tables, security rules, and pre-seeds all 45 Terry Corner meals with current prices).

  4. Copy Credentials: Go to Project Settings → API, copy the Project URL and anon public key, paste them in the form on the left, and click Save & Connect!
